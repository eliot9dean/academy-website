관리자(원장) 완전 가이드

학원의 모든 숫자를 한 화면에서 보고 결정하는 자리. 매일·매주·매월 무엇을 봐야 하는지를 화면 단위로 정리했습니다.

0. 첫 로그인 후 30분 셋업

  1. DB 관리 메뉴 → 사용자 탭에서 함께 일할 선생님·스탭 계정을 추가합니다.
  2. 학생/반 데이터를 가져옵니다 (엑셀 일괄 업로드 또는 직접 입력).
  3. 좌측 상단 사용자 패널의 🔑 아이콘으로 비밀번호를 변경합니다.
  4. 우측 상단의 "📅 오늘 날짜"가 시스템 기준일과 맞는지 확인합니다.
처음에는 테스트 계정으로 화면을 둘러본 뒤, 실제 데이터를 가져오는 것을 권장합니다. 테스트 모드는 어떤 입력을 해도 실제 DB에 반영되지 않습니다.

1. 일정 관리 (📅)

학원 전체 일정을 캘린더 형태로 관리하는 화면입니다.

화면 상단의 마케팅 티커

화면 최상단을 가로지르는 파란 박스 "뼈때리는 마케팅"은 봄날(bomnal.net) 칼럼의 최신 글을 자동으로 보여줍니다.

  • 흘러가는 제목을 클릭하면 해당 글이 새 탭에서 열립니다.
  • 학원 마케팅 인사이트를 매일 짧게 흡수하기 좋은 코너입니다.

일정 카드 만들기

  • "+ 일정 추가" 버튼 → 제목·날짜·시간·반·메모 입력
  • 색상으로 카테고리(수업/시험/공휴일/내부미팅) 구분
  • 반복 일정은 "매주", "매월" 옵션으로 한 번에 등록

2. 데일리 리포트 (📨)

선생님이 매일 작성한 수업 보고서를 한 페이지에서 모아보는 화면입니다.

무엇을 볼 수 있나

  • 어떤 선생님이 오늘 어느 반에서 무엇을 했는지
  • 학생별 출결 / 숙제 / 시험 점수 / 관찰 메모
  • 결석·미숙제 학생의 자동 하이라이트

이 화면을 매일 18:00 이후 5분만 봐도 학원의 70%가 보입니다.

3. 등록전환율 (📊)

상담 → 시범수업 → 정식 등록의 깔때기(funnel)를 분석합니다.

핵심 지표

  • 상담 건수: 이번 달 신규 상담 인원
  • 시범수업 전환율: 상담 중 몇 %가 시범까지 왔는가
  • 등록 전환율: 시범수업 중 몇 %가 정식 등록으로 이어졌는가
  • 유입 경로별 전환율: 지인 추천 / 광고 / 검색 / 기타

4. 퇴원 분석 (📉)

학원 매출의 진짜 적은 신규 등록 부족이 아니라 이탈입니다.

  • 월별 퇴원 인원 추이
  • 퇴원 사유 분포 (성적 / 비용 / 친구관계 / 이사 / 기타)
  • 퇴원 직전 3개월의 출결·성적 패턴
  • 이탈 위험 학생 자동 추천 (출결률·점수 하락 학생)

5. 재무현황 (💰)

학원의 캐시플로우를 한 페이지에서 봅니다.

6. 선생님별 수업현황 (🏫)

7. DB 관리 (🗄️)

시스템의 모든 원본 데이터를 직접 보고 수정할 수 있는 관리자 전용 화면입니다.

이 화면은 수정이 즉시 시스템 전체에 반영됩니다. 단순 조회는 다른 메뉴를 사용하세요. 대량 수정은 반드시 백업(CSV 내보내기) 후 진행하세요.

8. 매일 / 매주 / 매월 루틴 추천

매일 (5분)

  • 데일리 리포트 — 결석·미숙제 확인
  • 마케팅 티커 글 1개 읽기

매주 월요일 (15분)

  • 퇴원 분석 — 이탈 위험 리스트
  • 등록전환율 — 지난주 상담 결과
  • 일정 관리 — 이번 주 일정 점검

매월 1일 (30분)

  • 재무현황 — 지난달 손익 마감
  • 퇴원 분석 — 사유 분포 회의 자료
  • DB 관리 — 신규 가입 일괄 승인

9. 자주 묻는 질문

Q. 데이터가 갑자기 사라진 것 같아요.

화면을 새로고침해 보세요. 시스템은 로컬 캐시 + 서버 동기화 이중 안전장치를 갖추고 있어 실제 데이터 소실은 거의 발생하지 않습니다. 그래도 안 보이면 우하단 💬 오픈톡 문의로 연락주세요.

Q. 선생님이 어제 입력을 깜빡했는데 소급해서 수정 가능한가요?

가능합니다. 데일리 리포트 화면에서 날짜를 선택해 과거 데이터를 직접 수정할 수 있습니다.

Q. 학부모에게 보여주고 싶지 않은 메모는 어떻게 분리하나요?

수업일지의 "관찰 메모"는 내부용입니다. 학부모 화면에는 표시되지 않습니다.
