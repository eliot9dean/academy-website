스탭(데스크) 완전 가이드

학원의 첫인상은 데스크에서 결정됩니다. 스탭은 "사람"과 "돈"의 흐름을 모두 관리하는 운영의 심장입니다.

1. 학생 정보 (👤)

학원의 모든 학생을 한눈에 보고 검색·필터·수정하는 마스터 화면입니다.

핵심 기능

  • 이름·학년·전화번호 검색
  • 반·학년·재원 상태별 필터
  • 학생 카드 클릭 → 상세 페이지 (출결/성적/수강료/상담 통합)

2. 수강 관리 (📒)

학생별 수강중인 반과 수강료 상태를 관리합니다.

수강료 누락 방지 체크리스트

날짜해야 할 일
매월 1일신규 청구서 자동 생성 확인
매월 5일미납 알림 SMS 발송
매월 10일미납 학생 학부모에게 직접 통화
매월 25일다음달 수강 등록 안내

3. 교재 관리 (📚)

교재 재고와 학생별 지급 이력을 관리합니다.

  • 교재 입고 / 출고 / 재고
  • 학생별 교재 지급 이력 (반복 청구 방지)
  • 교재비 자동 청구 (수강료 합산 또는 별도 청구)
  • 부족 재고 알림

4. 재원 / 퇴원 관리 (📋)

학원 등록의 시작과 끝을 다루는 화면입니다.

등록 프로세스

  1. 상담 등록 — 전화/방문 상담 기록 (성함·연락처·상담 내용·관심 반)
  2. 시범수업 예약 — 일정 잡고 SMS 자동 발송
  3. 시범수업 결과 — 등록/보류/거절 입력
  4. 정식 등록 — 학생 정보 입력 + 첫 수강료 청구

퇴원 프로세스

  1. 퇴원 사유 청취 — 표준 카테고리 선택 + 자유 메모
  2. 마지막 수업일 확정
  3. 수강료 정산 (잔여일 환불 or 추가 청구)
  4. 시스템 상태를 "퇴원"으로 변경 — 학부모 계정 자동 비활성화
모든 퇴원 사유는 관리자 화면의 "퇴원 분석"에 자동 집계됩니다. 사유 입력에 성의를 다해주세요. 한 줄의 메모가 학원의 다음 분기를 바꿉니다.

5. 재무 관리 (💰)

스탭이 직접 다루는 일일 금전 관리 화면입니다.

6. 학부모 응대 시 화면 활용

전화/방문 상담 중 가장 빛나는 사용법입니다.

학부모 전화가 왔을 때 (30초 안에 준비)

  1. 학생 정보 → 검색 → 학생 카드 클릭
  2. 한 화면에서 보이는 것:
    • 최근 출결 / 점수 / 숙제 상황
    • 담임 선생님의 관찰 메모
    • 수강료 납부 상태
    • 지난 상담 기록
  3. 이 정보로 학부모의 어떤 질문에도 즉시 응답 가능

7. 매일 / 매주 / 매월 루틴

매일 (15분)

  • 신규 상담 입력
  • 입금 처리
  • 미납 1차 안내 SMS

매주 월요일 (30분)

  • 지난주 시범수업 결과 정리
  • 등록전환율 보고
  • 신규 등록자 환영 SMS

매월 1·5·10·25일

  • 1일: 청구서 일괄 발송
  • 5일: 미납 알림
  • 10일: 미납 직접 통화
  • 25일: 다음달 등록 안내

8. 자주 묻는 질문

Q. 학부모가 영수증을 종이로 달라고 해요.

입금 확인 후 영수증 PDF를 출력해 발행하세요. 학부모용 SMS에는 "영수증 보러가기" 링크가 자동 첨부됩니다.

Q. 형제 할인을 적용하려면?

수강 관리 → 학생 선택 → "할인 코드" → "형제 할인 (X%)" 선택. 자동으로 매달 적용됩니다.

Q. 두 명의 스탭이 동시에 같은 학생을 수정하면?

시스템은 마지막 저장을 우선으로 합니다. 다만 화면이 실시간 동기화되므로 충돌 가능성은 매우 낮습니다.
