학원관리 시스템 — 전체 개요

4개 역할(관리자 · 선생님 · 스탭 · 학부모)이 하나의 시스템에서 협업하도록 설계된 학원 운영 통합 솔루션입니다.

이 시스템이 해결하는 문제

기존 학원 운영의 가장 큰 비효율은 데이터의 분산입니다. 출결은 종이로, 성적은 엑셀로, 수강료는 회계 프로그램으로, 학부모 소통은 카톡으로 — 같은 학생의 정보가 4~5개 도구에 흩어져 누가 어디까지 알고 있는지 매번 확인해야 합니다.

이 시스템은 "한 학생의 모든 것을 한 곳에서" 라는 원칙으로 모든 데이터를 통합합니다. 출결 → 진도 → 숙제 → 시험 점수 → 관찰 메모 → 상담 → 수강료 → 데일리 리포트가 학생 단위로 자동 연결됩니다.

데이터 흐름의 큰 그림

[선생님] 출결·진도·숙제·점수·관찰 입력
            ↓
[시스템] 학생별 누적 데이터 생성
            ↓
   ┌────────┴────────┬─────────────┐
   ↓                 ↓             ↓
[학부모]         [관리자]       [스탭]
자녀 현황        데일리 리포트   상담 기록
                 등록전환율     수강료 관리
                 퇴원 분석

선생님이 입력한 한 번의 데이터가 학부모(즉시 확인) → 관리자(분석) → 스탭(상담 자료)로 자동 흘러갑니다. 중복 입력 0회가 이 시스템의 핵심 가치입니다.

네 역할이 같은 데이터를 다르게 본다

👑
관리자가 보는 것
전체 출결률 · 결석 학생 수 · 수강료 미납 총액 · 이번달 신규 등록
📚
선생님이 보는 것
내 담당반의 학생별 출결 · 진도 · 점수 · 숙제 · 관찰 메모
🖥️
스탭이 보는 것
학생 카드 · 수강료 청구 · 미납 · 상담 이력 · 교재 재고
👨‍👩‍👧
학부모가 보는 것
자녀의 이번 주 출결 · 최근 점수 · 오늘 진도 · 다음 시험

기술적 특징

  • 실시간 동기화 — 선생님이 입력하면 학부모 화면에 즉시 반영 (Supabase Realtime).
  • 오프라인 안전성 — 네트워크가 끊겨도 로컬에 저장 → 다시 연결되면 자동 업로드.
  • 다탭/다기기 — 같은 계정으로 여러 기기에서 동시에 사용해도 데이터 충돌 없음.
  • 테스트 모드 — 실제 데이터를 건드리지 않고 기능을 자유롭게 체험할 수 있는 별도 모드.
  • 역할 기반 접근 — 학부모는 자녀의 데이터만, 선생님은 본인 담당반만 — 자동 분리.

"이 시스템을 도입하고 첫 한 달은 입력 시간이 늘어난 듯 느껴집니다. 두 달째부터는 학부모 상담 응대 시간이 절반으로 줄고, 원장이 매일 보는 숫자가 명확해집니다."
