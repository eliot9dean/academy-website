모든 사용자를 위한 공통 팁

역할에 상관없이 알아두면 시스템을 두 배 빠르게 쓸 수 있는 팁들을 모았습니다.

1. 사이드바 접기 / 펴기

좌측 상단의 ☰ 버튼을 누르면 사이드바가 좁아져 화면을 더 넓게 쓸 수 있습니다. 좁은 모니터(13인치 이하)에서는 항상 접어두는 것을 권장합니다.

2. 두 가지 외부 링크 버튼

사이드바 하단: "1:1 마케팅 상담" 💬

학원 운영자(원장 · 스탭)가 마케팅 컨설팅이 필요할 때 사용하는 전용 채널입니다. 광고 효율 / 등록 전환 / 상담 응대 매뉴얼 / 카피라이팅 등.

우측 하단 플로팅: "오픈톡 문의" 💬

모든 사용자가 시스템 사용 중 막히는 부분을 즉시 묻는 곳입니다. 화면이 안 열릴 때, 데이터가 이상할 때, 새로운 기능 요청, 버그 리포트.

3. 비밀번호 보안

  • 첫 로그인 후 반드시 비밀번호를 변경하세요 (좌측 상단 사용자 패널의 🔑)
  • 학원 PC에서 로그아웃을 깜빡했다면, 다른 PC에서 로그인 후 비밀번호 변경 → 모든 세션이 자동 종료됩니다
  • 비밀번호 분실 시 로그인 화면의 "비밀번호 찾기"를 사용하세요

4. 다탭 / 다기기 사용

  • PC에서 입력하면서 휴대폰에서 보는 등 동시 사용이 가능합니다
  • 한 기기에서 입력한 내용은 다른 기기에 자동으로 반영됩니다
  • 같은 행을 두 사람이 동시에 수정하면 마지막 저장이 우선됩니다

5. 데이터가 이상해 보일 때 체크리스트

  1. 새로고침 — 가장 먼저 시도. 80%의 문제가 해결됩니다.
  2. 다른 메뉴로 이동 후 돌아오기 — 캐시 갱신
  3. 로그아웃 후 재로그인 — 세션 갱신
  4. 다른 브라우저로 시도 — Chrome 권장
  5. 그래도 안 되면 우하단 💬 오픈톡 문의 사용

6. 모바일 사용 팁

  • iPhone Safari / Android Chrome 모두 정상 동작합니다
  • 화면 우상단 "공유 → 홈 화면에 추가"로 앱처럼 만들 수 있습니다
  • 표 입력은 가로 모드(landscape)가 훨씬 편합니다

7. 키보드 단축키 (PC)

키동작
Ctrl + S현재 화면 저장
Esc모달 / 팝업 닫기
Tab다음 입력 칸으로 이동
Shift + Tab이전 입력 칸으로 이동
Ctrl + F학생/반 검색 (가능한 화면)

8. 자주 헷갈리는 용어

용어의미
반(Class)같은 시간대에 같은 교재로 수업하는 학생 그룹
수업일지선생님이 수업 직후 입력하는 통합 기록
데일리 리포트그날의 수업일지가 자동으로 모인 관리자/학부모용 보고서
관찰 메모학부모에게 보이지 않는 내부 메모
데일리/위클리 테스트수업 시간 내 시험 / 주간 종합 시험
재원 / 퇴원학원에 등록 중인 상태 / 정식 퇴원한 상태
휴원일시적 정지 (수강료 청구 멈춤)

9. 시스템이 잘 동작하는지 확인하는 30초 테스트

  1. 로그인 → 메뉴 하나 클릭 → 화면이 보임 ✅
  2. 사이드바 ☰ 버튼 클릭 → 접힘/펴짐 동작 ✅
  3. 우하단 💬 버튼 보임 ✅
  4. 어떤 데이터든 한 줄 수정 → 저장 → 새로고침 → 그대로 보임 ✅

이 4개가 모두 통과하면 시스템은 정상입니다.

10. 마지막으로

이 시스템은 사람이 사람을 가르치는 일을 더 잘 할 수 있도록 만든 도구입니다. 숫자와 데이터에 매몰되지 마시고, 매일 작게 들여다보며 학생 한 명 한 명의 변화를 따뜻하게 알아채는 데 사용해주세요.
