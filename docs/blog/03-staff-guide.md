# 스탭(데스크) 완전 가이드

> 학원의 첫인상은 데스크에서 결정됩니다. 이 시스템에서 스탭은 "사람"과 "돈"의 흐름을 모두 관리하는 운영의 심장입니다.

---

## 0. 첫 로그인

1. 관리자에게 받은 계정으로 로그인.
2. 사이드바에 5개 메뉴(학생 정보 · 수강 관리 · 교재 관리 · 재원/퇴원 · 재무 관리)가 보입니다.
3. 🔑 비밀번호 변경 후 시작.

---

## 1. 학생 정보 (👤)

학원의 모든 학생을 한눈에 보고 검색·필터·수정하는 마스터 화면입니다.

### 핵심 기능
- 이름·학년·전화번호 검색.
- 반·학년·재원 상태별 필터.
- 학생 카드 클릭 → 상세 페이지 (출결/성적/수강료/상담 기록 통합).

### 새 학생 등록
"+ 학생 추가" 버튼 → 필수 항목:
- 이름 / 학년 / 학교
- 학부모 연락처 (필수 — 자동 SMS 발송에 사용)
- 등록 반 (없으면 빈 칸 가능, 나중에 배정)
- 등록일 / 유입 경로 (마케팅 분석에 직결)

### 학부모 계정 자동 생성
학생 등록 시 "학부모 계정 자동 생성" 옵션을 켜면 시스템이 학부모용 로그인 계정을 만들어 SMS로 발송합니다.

---

## 2. 수강 관리 (📒)

학생별 수강중인 반과 수강료 상태를 관리합니다.

### 주요 작업
- 반 배정 / 변경 / 추가 등록
- 월 수강료 자동 계산 (반 단가 × 수강 일수 비례)
- 형제 할인·장기 등록 할인 등 **할인 코드** 적용
- 수강 시작일 / 종료일 관리

### 수강료 누락 방지 체크리스트
1. 매월 1일 — 신규 청구서 자동 생성 확인.
2. 매월 5일 — 미납 알림 SMS 발송.
3. 매월 10일 — 미납 학생 학부모에게 직접 통화.
4. 매월 25일 — 다음달 수강 등록 안내.

---

## 3. 교재 관리 (📚)

교재 재고와 학생별 지급 이력을 관리합니다.

### 다룰 수 있는 것
- 교재 입고 / 출고 / 재고
- 학생별 교재 지급 이력 (반복 청구 방지)
- 교재비 자동 청구 (수강료에 합산 또는 별도 청구 선택)
- 부족 재고 알림

### 운영 팁
- 학기 시작 2주 전: 등록 학생 기준으로 교재 필요량 자동 계산 → 한꺼번에 발주.
- 학기 중 추가 등록 시: 시스템이 자동으로 교재 지급 알림을 띄워 누락 방지.

---

## 4. 재원 / 퇴원 관리 (📋)

학원 등록의 시작과 끝을 다루는 화면입니다.

### 등록 프로세스
1. **상담 등록** — 전화/방문 상담 기록 (성함·연락처·상담 내용·관심 반).
2. **시범수업 예약** — 일정 잡고 SMS 자동 발송.
3. **시범수업 결과** — 등록/보류/거절 입력.
4. **정식 등록** — 학생 정보 입력 + 첫 수강료 청구.

### 퇴원 프로세스
1. **퇴원 사유 청취** — 표준 카테고리 선택 + 자유 메모.
2. **마지막 수업일 확정**.
3. **수강료 정산** (잔여일 환불 or 추가 청구).
4. **시스템 상태를 "퇴원"으로 변경** — 학부모 계정 자동 비활성화.

> **모든 퇴원 사유는 관리자 화면의 "퇴원 분석"에 자동 집계됩니다.** 사유 입력에 성의를 다해주세요. 한 줄의 메모가 학원의 다음 분기를 바꿉니다.

---

## 5. 재무 관리 (💰)

스탭이 직접 다루는 일일 금전 관리 화면입니다.

### 입금 처리
- 학부모가 입금 → 시스템에서 해당 학생 검색 → "입금 확인" 클릭.
- 부분 입금 / 합산 입금도 처리 가능.
- 영수증 발행 버튼 (PDF 자동 생성).

### 지출 입력
- 카테고리 선택 (인건비 · 임대료 · 교재비 · 마케팅 · 비품 · 기타).
- 영수증 사진 첨부 가능.
- 모든 지출은 관리자 "재무현황"에 즉시 반영됩니다.

### 미납 관리
- "미납자 리스트" 자동 생성.
- 일괄 SMS 발송 기능.
- 30일 이상 미납 시 빨간색으로 강조 → 관리자에게 자동 알림.

---

## 6. 학부모 응대 시 화면 활용

전화/방문 상담 중 가장 빛나는 사용법입니다.

### 학부모 전화가 왔을 때 (30초 안에 준비)
1. **학생 정보 → 검색** → 학생 카드 클릭.
2. 한 화면에서 보이는 것:
   - 최근 출결 / 점수 / 숙제 상황
   - 담임 선생님의 관찰 메모
   - 수강료 납부 상태
   - 지난 상담 기록
3. 이 정보로 학부모의 어떤 질문에도 즉시 응답 가능.

### 상담 후
- "상담 기록" 탭에 통화 내용 한 줄 메모 → 다음 상담 때 연속성 확보.

---

## 7. 매일 / 매주 / 매월 루틴

### 매일 (15분)
- 신규 상담 입력.
- 입금 처리.
- 미납 학생 1차 안내 SMS.

### 매주 월요일 (30분)
- 지난주 시범수업 결과 정리.
- 등록전환율 공유 (관리자에게 보고).
- 이번 주 신규 등록자 학부모에게 환영 SMS.

### 매월 1일 / 25일 (1시간)
- 1일: 청구서 일괄 발송.
- 5일: 미납 알림.
- 10일: 미납 직접 통화.
- 25일: 다음달 등록 안내.

---

## 8. 자주 묻는 질문

**Q. 학부모가 영수증을 종이로 달라고 해요.**
A. 입금 확인 후 영수증 PDF를 출력해 발행하세요. 학부모용 SMS에는 "영수증 보러가기" 링크가 자동 첨부됩니다.

**Q. 형제 할인을 적용하려면?**
A. 수강 관리 화면에서 학생을 선택 후 "할인 코드" → "형제 할인 (X%)" 선택. 자동으로 매달 적용됩니다.

**Q. 휴원/복원 처리는 어디서?**
A. 재원/퇴원 관리 화면에서 학생을 선택해 "휴원" 상태로 변경. 휴원 기간 동안 수강료 청구가 자동 정지됩니다.

**Q. 두 명의 스탭이 동시에 같은 학생을 수정하면?**
A. 시스템은 마지막 저장을 우선으로 합니다. 다만 화면이 실시간 동기화되므로 다른 스탭의 변경 사항이 즉시 반영되어, 충돌 가능성은 매우 낮습니다.

**Q. 환불 처리는 어떻게 하나요?**
A. 재무 관리 → 해당 학생 → "환불" 버튼. 사유와 금액 입력 → 자동으로 회계상 마이너스 항목으로 기록됩니다.
