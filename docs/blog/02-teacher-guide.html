선생님 완전 가이드

선생님이 입력한 한 줄이 학부모 화면 → 원장 분석 → 스탭 상담으로 자동으로 흐릅니다. 하루 5분의 입력이 학원 전체를 움직입니다.

0. 첫 로그인

  1. 관리자에게 받은 이메일/비밀번호로 로그인합니다.
  2. 좌측 상단 사용자 패널의 🔑 아이콘으로 비밀번호를 변경하세요.
  3. 사이드바에 "내 담당반", "수업일지" 두 메뉴가 보입니다.

1. 내 담당반 (📚)

내가 수업하는 모든 반이 카드 형태로 나열됩니다.

카드에서 한눈에 보이는 정보

  • 반 이름 / 요일 / 시간 / 교재
  • 등록 학생 수
  • 이번 주 출결률 (퍼센트)
  • 미완료 숙제 인원

반 카드 클릭 → 반 상세 페이지의 4개 탭

탭입력학부모 노출
출결출/지/결/조퇴 토글, 일괄 처리 버튼✅ 즉시
진도오늘 단원·페이지·활동, "지난 수업 복사" 버튼✅ 즉시
숙제 / 점수숙제 체크 + 데일리·위클리 점수✅ 즉시
관찰 메모학생별 자유 메모❌ 내부용

2. 수업일지 (📝)

오늘 진행한 모든 수업을 한 페이지에 통합 입력하는 화면입니다.

입력 흐름 (수업 직후 5분 루틴)

  1. 상단에서 반 선택
  2. 출결 — 결석자만 체크 (기본 출석)
  3. 진도 — 오늘 한 부분 한 줄
  4. 숙제 — 다음 시간까지 할 것 한 줄
  5. 시험 점수 — 본 시험이 있으면 즉석에서
  6. 관찰 — 눈에 띄는 학생 1~2명만 한 줄씩
  7. 저장 → 자동으로 데일리 리포트로 흘러갑니다
"지난 수업 복사" 기능을 적극 활용하면 진도 입력 시간이 30초로 줄어듭니다. 관찰 메모는 긍정/부정 양쪽을 함께 기록하세요. 좋은 점만 쓰면 학부모 상담 자료가 빈약해집니다.

3. 점수 입력의 황금 룰

학부모가 가장 민감하게 반응하는 데이터가 점수입니다.

  • 시험 다음 날 오전까지 모든 점수 입력 완료 (지연될수록 신뢰도 하락)
  • 0점은 반드시 사유 메모 같이 입력 (미응시인지, 진짜 0점인지)
  • 평균이 큰 폭으로 떨어진 학생 → 즉시 관찰 메모에 한 줄 → 스탭이 학부모 상담 시 활용

4. 매일 / 매주 루틴

매 수업 직후 (5분)

  • 출결 체크
  • 진도 한 줄
  • 숙제 한 줄

매일 퇴근 전 (10분)

  • 관찰 메모 — 인상적인 학생 1~2명
  • 채점 끝난 시험 점수 입력

매주 금요일 (15분)

  • 이번 주 출결률 학생별 점검
  • 출결률 80% 미만 학생 메모

5. 자주 묻는 질문

Q. 어제 출결을 잘못 입력했어요.

출결 탭에서 어제 날짜로 가서 직접 수정 가능합니다. 변경 즉시 학부모 화면에도 반영됩니다.

Q. 다른 선생님 반 데이터를 볼 수 있나요?

보안상 본인 담당반만 표시됩니다. 다른 반 정보가 필요하면 관리자/스탭에게 요청하세요.

Q. 학부모가 점수를 보고 항의해요.

학생 카드 → 점수 추이 그래프 + 관찰 메모를 같이 보여주세요. 단일 점수가 아닌 흐름과 맥락으로 설명하는 것이 가장 효과적입니다.

Q. 휴대폰으로도 입력 가능한가요?

가능합니다. 사이드바는 자동으로 접히며, 모든 화면이 모바일 폭에 맞게 재배치됩니다. 다만 점수 일괄 입력은 PC가 더 빠릅니다.
