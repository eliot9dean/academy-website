학부모 완전 가이드

자녀가 학원에서 무엇을 배우고, 어떻게 자라고 있는지 — 매일 1분이면 충분히 보입니다.

0. 첫 로그인

  1. 학원에서 받은 SMS의 링크를 누르거나, 직접 사이트 주소로 접속
  2. 학부모님 이메일과 임시 비밀번호로 로그인
  3. 좌측 상단 🔑 아이콘으로 본인만 아는 비밀번호로 변경

1. 자녀 현황 (🏠)

로그인하면 바로 보이는 메인 화면. 자녀의 모든 학원 활동이 한 페이지에 정리되어 있습니다.

2. 화면 구성 6구역

구역보이는 내용
① 자녀 선택형제·자매가 등록된 경우 상단에서 자녀 전환
② 이번 주 출결월~토 요일별 출/지/결, 빨간 점으로 강조
③ 최근 진도어제·오늘 무엇을 배웠는지 + 다음 시간 숙제
④ 시험 점수 추이최근 시험을 그래프로 누적 (평균 비교 가능)
⑤ 오늘의 한 줄담임 선생님이 자녀에 대해 남긴 짧은 메모
⑥ 일정 / 수강료다가오는 시험·휴강·특강 + 청구·납부 상태

3. 매일 1분 사용법

자녀가 학원에서 돌아왔을 때:

  1. 출결 — 오늘 잘 갔다 왔는지 확인
  2. 진도 — 무엇을 배웠는지 보고 자녀와 한마디 ("오늘 ○○ 배웠다며?")
  3. 숙제 — 다음 시간까지 할 것 확인

이 1분이 자녀의 학습 동기를 매일 작게 끌어올립니다.

4. 시험 점수를 보는 법

점수 그래프를 볼 때 가장 중요한 것은 단일 점수가 아니라 흐름입니다.

  • 최근 5회 평균이 우상향 → 잘 가고 있는 신호
  • 단발적 하락 → 컨디션 / 단원 난이도 문제일 수 있음
  • 3회 연속 하락 → 학원에 상담 요청 권장
화면에는 점수만 나오지만, 학원에서는 그 뒤의 맥락(컨디션·집중도·이해도)을 알고 있습니다. 숫자만 보고 자녀를 다그치기 전에 학원에 한 번 전화해 사정을 확인하세요.

5. 학원과의 소통

학원 → 학부모

  • 결석 시 자동 SMS
  • 시험 일정 / 휴강 / 특강 공지가 화면 + SMS로 전달
  • 학원장 또는 데스크의 일대일 메시지가 있으면 화면 상단에 알림 표시

학부모 → 학원

  • 자녀 화면 우측 상단의 "학원에 문의하기" 버튼
  • 우측 하단의 💬 "오픈톡 문의" 플로팅 버튼은 일반 문의 전용 채널입니다

6. 자주 묻는 질문

Q. 비밀번호를 잊어버렸어요.

로그인 화면의 "비밀번호 찾기"를 누르면 가입한 이메일로 재설정 링크가 발송됩니다.

Q. 자녀가 둘 이상인데 따로 로그인해야 하나요?

한 계정으로 모든 자녀를 한 화면에서 볼 수 있습니다. 상단의 자녀 전환 버튼을 사용하세요.

Q. 점수가 잘못된 것 같아요.

학원에 직접 문의하세요. 담임 선생님이 확인 후 즉시 수정합니다.

Q. 자녀의 학원 데이터를 PDF로 받고 싶어요.

자녀 현황 화면의 우측 상단 "📄 리포트 다운로드" 버튼을 누르면 한 학기 누적 데이터를 PDF로 받을 수 있습니다.
